# 夕帆 · Sunset Galleon

复刻 [@Da7_Tech 的 Kimi 帆船案例](https://x.com/Da7_Tech/status/2113739589693460938)：夕阳落日下、海面上航行的三桅帆船，高保真实时 3D 动画。单文件、无构建、仅依赖 three.js CDN。

![晚霞模式](previews/晚霞_镜头二_贴水金波.png)

## 运行

```bash
cd sunset-sail
python3 -m http.server 8923
# 打开 http://127.0.0.1:8923
```

（需联网加载 three.js CDN；直接双击 index.html 以 file:// 打开也可以。）

## 对照案例的三个比拼点

| 维度 | 实现 |
| --- | --- |
| **水** | 6 组 Gerstner 波浪顶点位移（CPU 同参数采样驱动船体浮沉/纵倾/横摇）、三尺度流动细节法线、浪脊白顶泡沫 + 陡坡风向碎浪条 + 浪面直绘的船体水线/艏部破浪泡沫（无平面贴片，永不穿模）、逆浪次表面透光、三层碎金波光（760/160/64 次幂）、**真实平面反射**（镜像相机 RT：船体与帆倒影入水，随波法线扰动）、日方位地平线光带、船艉泡沫尾迹带 |
| **帆** | 三桅七面方帆 + 艏斜桅三角前帆：顶点着色器风压鼓胀（随阵风起伏）、边缘高频颤动、缝线纹理与褶皱明暗、逆光透射金色发光；主桅顶红旗行波飘动 |
| **运镜** | 四镜头循环：左舷逆光俯拍 → 贴水金波 → 艉迹环绕 → 艏前推进；贝塞尔路径 + 手持微晃 + 呼吸变焦 + 微量横滚，可随时切自由视角 |
| **天气** | 三模式循环切换（按钮或 `W` 键），**3 秒平滑渐变**（太阳/月亮高度、天空、海色、光照连续过渡，渐变期间锁定不可再切）：**日出** —— 太阳悬在海平线上方，金橙暖调；**晚霞** —— 太阳沉到海平线边缘，玫瑰紫天空 + 火烧云带；**深夜** —— 半空升起的月亮、星空闪烁、凌晨冷蓝光线，三层碎金波光化作破碎的银色月光海面。每种模式配有文字感悟（画面下方渐显） |
| **音乐** | 浪漫钢琴背景曲《最伟大的作品》纯器乐版（抖音热传的钢琴演奏片段），首次点击/按键自动响起并渐入，音量 35%，循环播放；面板按钮或 `M` 键开关（注意：音频仅供本地个人试听，公开部署网站前请先确认音乐版权授权） |

## 其它

- 船体为程序化放样建模（站点插值截面），带金色舷缘护栏、暖光炮窗/艉窗、艉楼灯笼点光源、主桅瞭望台；帆面细分网格顶点着色器鼓风，逆光透射金色发光
- 夕阳大气：地平线琥珀 → 桃色 → 暗橄榄灰渐变天空、日面 HDR 光晕、远海暖霾融合、薄暮海鸥剪影
- 后期：ACES 色调映射 + 轻量 Unreal Bloom（高阈值，日面轮廓清晰不过曝）+ FXAA + 暗角暖调
- 自适应画质（持续低帧率自动降级）；操作：`空格` 暂停 · `C` 自由视角 · `W` 循环切换天气（日出→晚霞→深夜，3s 渐变） · `M` 音乐开关 · `Q` 画质
- 移动端兼容：噪声哈希对大坐标做 4096 取模包裹（长时间航行坐标增大不产生网格崩坏，手机/PC 通用）；着色器所有 `pow` 底数做非负钳制（规避 Mali/Adreno 等 GPU 对负数底数 `pow` 返回 NaN 造成的黑色垃圾块）

## 关于背景音乐

代码里的 `bgm.mp3` 是本地私人使用的钢琴演奏录音（周杰伦《最伟大的作品》翻弹，版权归原权利人所有），**公开仓库不包含该文件**（见 `.gitignore`）。不影响任何画面功能：音频缺失时音乐按钮会自动置灰显示「音乐 · 无」。如需自行启用，把任意 mp3 命名为 `bgm.mp3` 放在本目录即可。
